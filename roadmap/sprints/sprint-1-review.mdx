### Aprendizados (para o doc de versões)

1. **Peek vs current:** logos avança o cursor; guardar span no token **já lido** é obrigatório para diagnósticos corretos.
2. **Paths Windows:** extrair `linha:coluna` pelo sufixo `: error:`, não por `split(':')` no path completo.
3. **Check silencioso:** `quiet_diagnostics` separa UX de IDE (stderr) de debug interativo (println).
4. **Próximo passo natural:** levar spans à **semântica** (S2/S3), não adiar para S8.
