# Squad CrabPascal — Papéis, nomes e governança

Objetivo da squad: entregar um **compilador Delphi-like acima da média do mercado** — não “mais features no papel”, mas **compatibilidade real**, **diagnósticos confiáveis**, **testes que não mentem** e **paridade** entre `run`, `check` e `build`.

Documento de versões: `SPRINTS_VERSOES.md`\
Review técnica: `REVIEW_COMPILADOR_2026_360.md`

---

## Princípio de foco (produto acima da média)

Toda tarefa precisa responder **sim** a pelo menos uma destas perguntas:

1. Isso faz um projeto Delphi **real** compilar/rodar melhor do que antes?
2. Isso reduz **surpresa** (run funciona, build quebra)?
3. Isso melhora **DX** (erro na linha certa, IDE útil)?
4. Isso está coberto por **teste** que falha se regredir?

Se a resposta for “não” para todas → **não entra na sprint** (vai para backlog).

## Rituais da squad (leve, mas firme)

### Diário (async ou 15 min)

- **Rafael** pergunta: “O que bloqueia valor hoje?”
- Cada dev: 1 linha — feito / hoje / bloqueio.
- **Marina** reporta: testes vermelhos e regressões novas.

### Meio da sprint

- **Review de foco:** Rafael \+ Helena — ainda estamos na meta da sprint ou estamos cavando buraco lateral?
- **Marina** roda matriz mínima da sprint (não espera o fim).

### Fim da sprint (Definition of Done)

- Critérios de aceitação de `SPRINTS_VERSOES.md` cumpridos
- `cargo test` verde
- Harness acordado verde (ou falhas documentadas com issue)
- Changelog \+ bump de versão (extensão e/ou binário, conforme release)
- Nada de “funciona só no meu PC” — Marina reproduziu

### Quando QA devolve

1. Marina abre/descreve: **passos**, **esperado vs obtido**, **comando** (`check` / `run` / `build`).
2. Dono da área corrige — **não** “fecha sem teste”.
3. Marina revalida — só então Rafael marca sprint item como done.

## Como usar agentes (Cursor) com esta squad

Cada “agente” de exploração/implementação no Cursor deve ser invocado **com o chapéu** de um membro:

| Agente / prompt | Atuar como | Foco |
| --- | --- | --- |
| Exploração arquitetura | Rafael \+ Helena | Pipeline, riscos, não sair do escopo |
| Parser / lexer | Bruno | Spans, recovery, AST shape |
| Semântica / tipos | Helena | Menos permissivo, overload, properties |
| Runtime / RTL | Helena \+ Bruno | Intrinsics, units, comportamento Delphi |
| Codegen / build | Lucas | Paridade, stubs, exe real |
| IDE / extensão | Camila | Problems, tasks, UX |
| Testes / CI | Marina | Matriz, regressão, flaky HTTP |

**Template de prompt para subagente:**

```text
Você é [NOME], [PAPEL] da Squad CrabPascal.
Sprint atual: [Sx] — [versão] — ver SPRINTS_VERSOES.md.
Regra: só proponha/implemente o que entrega valor ao critério de aceitação da sprint.
Se encontrar escopo extra, liste em "Fora da sprint" e não implemente sem OK do Rafael.
Inclua sempre: testes + como validar (check/run/build).
```
