## 📋 **IMPLEMENTAÇÃO:**

### **FASE 1: TDictionary\<K,V\> Template (3-4h)**

**1.1 Criar template no runtime:**

```pascal
TDictionary<TKey, TValue> = class
private
  FKeys: array of TKey;
  FValues: array of TValue;
  FCount: Integer;
public
  procedure Add(Key: TKey; Value: TValue);
  function TryGetValue(Key: TKey; var Value: TValue): Boolean;
  function ContainsKey(Key: TKey): Boolean;
  function Count: Integer;
end;
```

**1.2 Implementar hash function:**

```rust
fn hash_value(&self, value: &Value) -> u64 {
    match value {
        Value::Integer(i) => *i as u64,
        Value::String(s) => simple_string_hash(s),
        _ => 0
    }
}
```

**1.3 Implementar métodos:**

- Add: Busca por key, atualiza ou adiciona
- TryGetValue: Busca e retorna via var parameter
- ContainsKey: Verifica existência
- Count: Retorna FCount
