## Preview local

```bash
cd mintlify
mint dev
```

Abre em `http://localhost:3000`.

## Sincronizar a partir de `documentation/` e `docs/`

```powershell
powershell -ExecutionPolicy Bypass -File mintlify/scripts/migrate-docs.ps1
```

Revisa `docs.json` manualmente se adicionar paginas novas.

## Deploy no Mintlify (Git)

1. Crie conta em [mintlify.com](https://mintlify.com)
2. **New documentation** → conecte o repositorio Bitbucket/GitHub
3. Defina **docs directory** = `mintlify`
4. Branch de deploy: `main` (ou a branch desejada)
5. Mintlify faz build automatico a cada push

### Dominio customizado

No dashboard Mintlify: **Settings → Domain** → configure CNAME.

## Admin MCP (editar via Cursor)

Para o agente editar paginas diretamente no Mintlify:

1. `Ctrl+Shift+P` → **Open MCP settings**
2. Adicione:

```json
{
  "mcpServers": {
    "mintlify": {
      "url": "https://mcp.mintlify.com"
    }
  }
}
```

3. Reinicie o Cursor e faca login OAuth no projeto CrabPascal.

## Docs MCP (busca publica)

Apos publicar, o MCP de leitura fica em:

```text
https://<seu-subdominio>.mintlify.app/mcp
```
