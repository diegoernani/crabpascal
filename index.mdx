## Versão atual: **v2.22.0** (26/05/2026)

O CrabPascal evoluiu de um interpretador experimental (v1.x, out/2025) para um **pipeline completo** de compilador com sprints quinzenais desde maio/2026.

| Área | Estado |
| --- | --- |
| Diagnósticos (`check`) | Spans reais, problem matcher IDE |
| RTL `System.*` | SysUtils, Classes, Generics, IOUtils |
| OO / Properties | Runtime \+ accessors por método |
| Unicode | UTF-16 em strings Delphi |
| Run / Build | Paridade crescente; codegen honesto em exceptions |
| Horse HTTP | Rotas parametrizadas \+ testes E2E (Sprint 16) |

## Comandos essenciais

```bash
crab-pascal check programa.dpr    # diagnósticos com linha/coluna
crab-pascal run programa.dpr      # interpretador / runtime
crab-pascal build-exe programa.dpr # gera executável via toolchain C
```
