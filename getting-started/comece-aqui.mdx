# 🦀 **CrabPascal v2.8.0 - Comece Aqui!**

**Bem-vindo ao CrabPascal - Pascal with Rust Claws!**

---

## 🎯 **O Que É CrabPascal?**

Compilador Pascal moderno escrito em Rust que oferece:

✅ **Compilação ultra-rápida** (~5ms)\
✅ **Zero dependências** (não precisa de Delphi/FPC)\
✅ **OOP completo** (classes, herança, polimorfismo)\
✅ **Generics** (TList\<T\>, TDictionary\<K,V\>)\
✅ **APIs RESTful** (Horse framework)\
✅ **Extensão VSCode** (Marketplace)\
✅ **Production Ready** (100% testado)

---

```bash

```
